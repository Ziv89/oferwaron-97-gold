How It Works

Each animation uses multiple copies of the same silk image layered on top of each other with different:

• mix-blend-mode (soft-light, overlay, screen) for blending
• opacity levels for depth
• transform animations (translate, scale, skew, rotate) at different speeds

This creates the illusion of the actual fabric folds moving and waving!
